# Go v0 technical preview: 0.1.0-alpha.1

This preview packages the current Go CLI and its compiled, in-code CORE/PL/EN
catalog. It is a technical milestone, not an acceptance claim for translation.

## Available now

- `--help`, `--version`, and `capabilities --json` report CLI and translation
  readiness; `ready` is false until approved language providers are configured.
- `catalog --summary --json` reports 49 described CORE concepts toward an
  editorial target of about 1000, PL 16 lexemes/20 senses, EN 19 lexemes/28
  senses, and zero approved PL+EN concept pairs. `--details` adds each stable
  ConceptID with separate language status.
- `forms --language pl|en` generates declared inflected forms from a lexeme
  ID and feature bundle or analyzes a surface against the finite inverse
  index. The scope is the documented small [PL](../languages/pl.md) and
  [EN](../languages/en.md) seeds.
- `question` evaluates a typed request supplied with its own MeaningGraph,
  FactSet, rule selection, and CORE runtime config. It does not parse or
  realize natural-language questions.
- Meaning JSON operations and bounded, provenance-bearing import/staging
  packages are available as documented in the architecture.

## Limits

`translate` is a guarded CLI entry point, but there are no approved
SenseID→ConceptID links or PL/EN construction bindings in active runtime
packages, and no trusted sentence providers are registered by default. It
returns `unsupported` for ordinary requests. There is no free-form sentence
analysis, realization, dialogue response surface, memory, learning, server,
TUI, SQL store, or performance guarantee. A `pending` catalog link is not a
translation license. No direct PL→EN mapping is used; future translation
must pass through language-neutral MeaningGraph/CORE and separately approved
language bindings.

## Review and build evidence

Go CI runs `gofmt`, `go vet ./...`, `go build ./cmd/golingua`, and CLI
`--help`/`--version`. It contains no automatic linguistic golds, parity with
the old JavaScript code, or grammar test suite. Manual quality assessment is
`NOT RUN` until the owner supplies PL/EN words or sentences and evaluates the
literal CLI output. Use [the manual review procedure](../manual-review.md).

This preview can be installed and inspected without implying PL↔EN sentence
translation. The remaining dependencies are tracked in G05 #123, G06 #128 and
#130, G07 #63, and G08 #65/#66.
