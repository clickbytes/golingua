# CORE inventory target

The editorial inventory target is 1000 distinct `ConceptDefinition` records. On the current branch, `catalog.Compile()` builds **1000/1000**: 49 preserved original definitions plus 951 adopted definitions from the owner-supplied proposal set. This is a count of compiled CORE definitions, not a score for translation quality. The TSV's `NO` is not an ID and its draft status is not a runtime status.

No PL or EN concepts are absent, and 698 concepts have approved lexical bindings in both languages. `pending` indicates a language-local candidate binding; it does not authorize transfer. `absent` means no binding exists in that language index. `approved` requires an explicitly reviewed, valid equivalent binding. The report does not promote candidates.
