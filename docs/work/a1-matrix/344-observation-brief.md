# #344 observation metadata

This bounded component adds structured metadata to the existing `TestInventory` and stage markers to existing matrix adapter observations. It also permits optional local `person` defaults for common noun routes, and optional `number` defaults for authored mass or unknown-count roles in A1.4/A1.8. These annotations do not alter meanings, required assumptions, text contracts, or semantic quantities.

Catalogue sense-to-lexeme associations describe pack data only. They are explicitly marked `morphology_executed:false` and do not claim runtime morphology coverage.
