# Bounded construction goals

These examples exercise the explicit `positive-facts-v1` goal shape. The
two-hop and three-hop files request a binary relation path and a unary
restriction; the one-hop file requests one relation. The fixed-reference file
binds a port to a declared reference.

`context_id` selects the caller's named request context. The accompanying
metadata file supplies an explicit neutral declaration package; its labels,
source references, and package identity do not constitute owner approval or a
claim about world facts. The renamed pair demonstrates that symbol and role
IDs, rather than display labels, carry the mapping.

The typed-hole and multiple-count examples remain underdetermined. They do not
select a witness or candidate. Resolving such goals belongs to later bounded
search work; none of these files asserts that a constructed proposition is
true in the world.
