# Bounded WH-question examples

These four punctuated inputs exercise explicit subject and object gaps in a separate, exact source-composition WH family. They use the #395 neutral metadata package and exact source plans; each context supplies the other frame role and an event reference. The WH form and final question mark are both consumed by the selected construction.

The source packages and plans are explicit runtime inputs. Their `SourceRef` records remain agent-authored proposals; this data is not owner language approval. The WH construction/valency records are linked only to the listed visual-perception frames and variants.

| Input | Text | Gap role | Other role reference |
|---|---|---|---|
| `cases/en-subject.json` | Who sees the dog? | experiencer | stimulus → B |
| `cases/en-object.json` | The teacher sees whom? | stimulus | experiencer → A |
| `cases/pl-subject.json` | Kto widzi psa? | experiencer | stimulus → B |
| `cases/pl-object.json` | Kogo widzi nauczyciel? | stimulus | experiencer → A |

The `Ask` answer variable is typed from the selected frame role port. It has type `Entity` without a `Person` restrictor, so these probes do not encode the full lexical semantics of `who/whom/kto/kogo`. These are bounded parser/composer examples, not natural-language coverage claims, world facts, or proof of owner acceptance. The observed PL object question uses the fronted order `kogo + verb + subject`; an echo question remains outside this set.
