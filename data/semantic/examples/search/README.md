# Bounded search inputs

These files are formal inputs for the finite `positive-facts-v1` search
profile. [metadata.json](metadata.json) declares the neutral primitive
relations used by the goals. A goal may have one candidate, several explicit
candidates, or no candidate within the declared finite profile; unresolved
choices and operational limits remain visible in the result.

The candidates are structural constructions with alpha-identity checks. They
do not assert world truth, select a speaker's intended meaning, or carry owner
language approval. The files contain no language-specific lexical mappings.
