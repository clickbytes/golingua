# Neutral proof examples

These files are small mathematical controls for the bounded proof commands in
issue #390. They are not language data or owner-approved meanings.

- `equivalence/` contains a typed predicate metadata package, two alpha-variant
  expressions, an explicitly licensed `alpha_v1` profile, and the comparison
  certificate and results captured from the branch CLI.
- `evaluation/` contains a positive-facts query, a finite explicit fact set, a
  selection, and a supplied proof with its verification result. The facts
  include opposing source evidence; positive support is checked without
  treating conflict as completeness or world truth.

The command forms and their limits are documented in
[the proof contract](../../../../docs/architecture/semantic-algebra/proofs.md).
Observed stdout, stderr, inputs, binary details, and exit codes are preserved
in the [evidence receipt](../../../../docs/work/dse/evidence/05-03/README.md).
