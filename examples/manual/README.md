# Ręczne wejścia użytkownika

**Na start brak wpisanych przykładów.** Zdania, słowa i kierunki PL↔EN podaje właściciel projektu w trakcie prac. Nie kopiować tutaj dawnej macierzy JS ani nie generować automatycznych „golden” zdań.

Jeżeli właściciel chce zachować krótki przykład z sesji, można utworzyć czytelny plik `.md` z wejściem, dokładnym wywołaniem CLI, *rzeczywistym* outputem, SHA i komentarzem. Ten folder **nie jest używany przez CI** i nie ma progów pokrycia.

Opis procedury: [docs/manual-review.md](../../docs/manual-review.md).
